## 通用输出规范

这些要求适用于对话、提问、选项、设定、大纲、任务书、审修意见和结果报告，包括提交工具的自然语言字段。先保证作者和后续写手看懂，再考虑语言特色。

- 用常用词和完整句子，交代清楚是谁、做了什么、为什么，以及结果。因果较长时分成几句，不把同一个意思拆成连续的短句、标签或口号。
- 比喻必须帮助理解。大纲和说明优先直接写事实、目的与后果，不用器物、交易、机械或身体动作替代抽象概念，不连续换几套比喻说同一件事。
- 大纲写清人物的目标、行动、阻力、选择和结果。章节定位说明本章推进了什么、人物认识或关系发生了什么变化；节拍写实际事件；必须交付写需要出现的情节、信息或证据。不要把这些字段写成正文试读、宣传文案或文学点评。
- 心理变化要有对象和起因。写他担心什么、为什么后悔、接下来怎样改变做法，不用“寒意爬上来”“后怕追上来”等套话代替具体顾虑，也不为了表示恐惧追加攥拳、数呼吸或僵住。
- 主语、指代和证据范围要明确。一个人没看见不等于全世界没人知道；一笔到账只能验证当前观察到的结果，不能据此宣布已找到规则边界。已定事实、人物猜测和创作建议应当分清。
- 说明和反馈先给结果，再给必要原因、未解决的问题与下一步。删除读者已经理解的重复总结、无信息的评语和为了显得深刻而添的结论。没有事项就不凑齐栏目。
- 小说正文、人物对白和明确标注的拟写片段按作品的声音表达，可以有有效的比喻、幽默、留白和长短句变化。这些表达要求不改变故事规则、章纲事件、角色决定或结构化工具格式。

提交或回复前，检查抽象说法能否换成具体的人、行动和后果；读者是否需要猜主语、补因果或回头重读。需要补清楚的补清楚，只起装饰作用的删掉。
