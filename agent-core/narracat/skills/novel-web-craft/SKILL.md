# 网文写作功底素材库

本库供压缩器组装章节任务书时取材，不直接提供给写手。先确认本章要写什么、哪里需要改善，再选择参考。

从下面选出**与本章最相关的2—3条**，结合章纲、作品声音和已选中的能力 pack，写进任务书「怎么写更顺」一段。要求应指出本章哪段展开、哪段略写，以及需要让读者理解什么。

写手读到的应当是针对本章人物、事件和场景的自然语言：哪里需要展开，哪里可以压缩，人物怎样反应，场景怎样衔接。不要转述通用条目，不要输出字段名、条目编号或 pack 名，也不要把素材库变成逐条执行的检查清单。

条目有重叠时合并表达；与章纲冲突时调整写法要求，不改写已定的事件、人物决定和结尾。短句、留白、比喻和反转都是可选办法，不能因为选中了某个参考就要求整章照做。逻辑在提炼时核对，正文只保留读者理解行动和心理变化所需的信息。

## 留人功底（取材条目）

读者在手机上阅读，需要尽快进入故事，也需要读得顺。这些条目说明要达到的效果，具体写法由作品的声音决定。同样是抓住读者，毒舌吐槽和沉静武侠应当有不同的节奏、语言与留白。

1. **开篇尽快进入故事。** 尽早让读者接触值得关注的人物、正在发生的事情，以及一个想继续了解的问题。可以从行动、对话、处境或反常细节进入，不必强行制造危机，也不必在第一段交齐背景。

2. **钩子落在重要变化上。** 疑问、反常和冲击来自具体事件，不按段落定额分配。章末从既定结尾事件中留下期待，可以是尚未得到的答案、刚作出的决定或即将承担的后果。不要为了加钩子，另造危机或改写结尾。

3. **段落有作用，推进有主次。** 一段可以推动事件，也可以帮助读者理解人物、感受气氛或完成衔接。重要段落应带来变化，普通段落可以直接叙述，不要求每段新增悬念、解释主题或落一句金句。

4. **眼前的阻力清楚。** 让读者知道人物想做什么、受到什么阻碍。阻力可以来自他人、环境、规则，也可以来自人物自身的顾虑。冲突不必都是争吵，但重要选择不能缺少可理解的原因。

5. **让读者顺着读懂。** 指代、时间、空间和关键因果要清楚。未知真相可以保留，人物眼前为什么行动要能理解。术语有实际用途时再用，搭配要自然；“可能”不能修复推理缺口，“没查到”不能直接写成“不存在”。场景已经表达的意思不再反复总结。

6. **用对白推动人物交往。** 从整场对话看，它应当影响信息、关系、计划或情绪，不要求每句话都交付新信息。主要人物的用词、态度、回避方式和关注点应有区别，这些区别来自身份与处境，不只依靠口头禅。

7. **先抑后扬要有原因。** 需要先抑后扬时，把具体的不公、阻力或危机写清楚，再让人物的行动带来释放。不要靠反复羞辱、无端误会或配角集体降智积攒情绪，也不要让每章都走同一种抑扬曲线。

8. **兑现本书承诺的爽点。** 让读者知道值得期待什么，并在关键处通过行动与结果兑现。扮猪吃虎通常需要让读者察觉主角有所保留，但不必提前揭开全部底牌；悬疑、成长、关系推进也应按各自的阅读期待安排满足感。

9. **用选择让读者记住人物。** 性格和经历影响他注意什么、怎样办事、在哪一步容易犯错。职业特点通过准确的办法和取舍表现，不把日常交往都翻成术语，也不编造专业流程。重要特质可以反复出现，但应随处境产生不同表现。

10. **留下具体的追读期待。** 章末让读者仍关心某件事：问题怎样解决，决定怎样执行，关系怎样变化，后果何时出现。也可以先兑现本章承诺，再留下新的期待。避免用“真正的危险才刚开始”代替实际进展。

11. **伏笔埋得自然，回收有依据。** 需要制造期待的伏笔，应让读者注意到值得记住的细节；需要隐蔽的伏笔，可以自然融入场景，不必逐个强调。揭开时，让前面的信息获得新意义，不临时改写旧事实来配合答案。

12. **台词的语气由整句话表达。** 先确定人物说话时的意图、态度和停顿，再选择用词与标点。“站住。”可以是压低声音的命令，“站住！”可以是急喊，具体含义取决于上下文。句号、感叹号、省略号都不自带固定情绪，不必为了区分人物而强行更换标点，也不要用标点堆叠代替表演。

13. **说话人始终清楚。** 可以用提示语、随话动作或前文位置交代说话人。连续对话中省略提示语很自然，前提是读者不会认错。提示语通常与台词或动作放在一起，不习惯性地把“她说。”单独列为一段。

14. **按内容组织句子和段落。** 连续动作、观察或思考通常放在同一段，换人说话、场景变化或注意力转移时再分段。短句可以强调重要发现，长句可以承载连续行动和思考；紧张不等于句子必须短。不按句号换行，也不把所有短段强并成长段。

15. **对白跟着人物的目的走。** 人物开口常在试探、遮掩、说服、拖延、靠近、拒绝或维护体面。他可以答非所问，也可以被打断，但反应应接住对方的话。两个人都知道的事情不为读者重念，角色不轮流替作者讲主题。

16. **主要场景带来变化。** 入场时弄清人物各自想得到什么，离场时检查信息、关系、计划、风险、判断或情绪是否发生变化。日常场景也可以加深读者对人物的理解，不必强造冲突。若只重复已知信息或同类反应，就压缩或合并。

17. **让心理影响行动。** 新经历使人物改变判断，具体顾虑影响他是否开口、求助、隐瞒或换办法。可以直接写心理，也可以借行为表现，不反复写同一种身体反应。配角同样有自己的事情、理由和局限，不只负责递消息、制造误会或夸主角。

18. **细节跟着人物的注意力走。** 写他此刻能知道、会留意的内容，不列满位置、朝向、数量和身体部位。细节有助于理解事件、人物或气氛即可，不必都成为象征。切换视角时交代清楚，对别人的内心判断保留当前人物的局限。

19. **在需要时说明设定。** 让读者先看见规则怎样影响行动、利益或代价，再补理解当前情节所需的说明。陌生名词分批引入。已知规则、人物猜测和误解要分清；异常可以违反常识，但载体、触发条件和作用范围要前后一致。

20. **把篇幅留给重要变化。** 关键选择、关系变化、秘密暴露和难以撤回的行动可以展开；重复劳动、赶路和已明白的过程可以概述。调查与验证重点写会增加证据、改变判断或造成后果的步骤，其余合并带过。留出人物反应和后续选择的篇幅，不用无意义的动作补字数。

21. **转折从已有条件中生长。** 关键转折优先来自人物此前的行动、关系、信息和已立规则。意外可以发生，但不反复替人物解决难题，也不只为拖延或升级情节而出现。转折改变了什么，人物为什么随后换办法，应让读者能够理解。

## 转化为章节要求时

优先指出本章最需要解决的一两个问题，写清具体处理方向。不要仅写“增强心理”“增加钩子”“降低认知负荷”。

例如，可以写：

> 开头的排查合并带过，只展开同事看不到公告的那次求证。重点写这次否定怎样使陈默不敢继续问人，以及他后来为什么仍决定联系母亲。连续的动作和思考合成完整段落，场景已经表达出的意思不再补总结。

这些要求服务于本章，不规定所有章节采用同一套情绪顺序、验证次数、段落长度或收尾方式。
