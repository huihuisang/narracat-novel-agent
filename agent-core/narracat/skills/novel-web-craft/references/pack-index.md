# 场景能力包索引

`pack-index.json` 保存程序选包所需的标识、触发词、标签与优先级。本表供压缩器查找参考，不投递给写手。

触发词命中后，仍要核对本章场景、人物与作品声音。只提取能解决当前写法问题的内容；不匹配时跳过，不为用上能力包改变章纲。各包的摘录用于比较写法，不移植其中的人物、情节或句式。
