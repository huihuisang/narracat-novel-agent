# 对峙与谈判（tense-dialogue）

写清双方想得到什么，以及怎样回应对方。

### [runtime] 写法参考

- **机制注解**：先明确双方的诉求、筹码和不能接受的结果。每次回应可以改变对方的判断、缩小选择范围，或暴露一项顾虑。紧张感来自说话会带来什么后果，不只来自反问、单字回答和停顿。

  一方可以承认事实，却拒绝接受对方提出的代价；也可以追问证据，或暂时避开关键问题。采用哪种办法，取决于他知道什么、能承担什么。人物可以明确说出诉求，不必句句都有潜台词。对话后的心理只补充尚未呈现的顾虑，不逐轮分析谁进谁退。

- **适用场景**：
  - 谈判、质问、审讯、摊牌，或关系中必须作出承诺的时刻。
  - 权力不对等，一方需要争取时间或保留选择。
  - 双方掌握不同信息，对同一件事有不同判断。

- **不可迁移边界**：
  - 不为精彩台词改变章纲结果，也不让人物知道尚未获得的信息。
  - 不要求双方同时软化，不把一次漂亮反问当成必然说服对方。
  - 对手可以拒绝、识破或另提条件，不因主角讲完一段话就自动认输。
  - 让读者知道谁在说话；动作和标点有需要时再用，不逐句配反应。

### [evidence] 真人证据（保留原有摘录）

- 真人证据：「"如果让你走呢？"郑千琴问他，"你违约了，这代价是离开唐彦。"

  "我知道。"姜危桥道，"那么我会走。"

  "哦？"

  "但是我还会再回来，再次追求他。无论您是否允许。"

  "你什么也不是。唐彦值得更好的。"

  姜危桥笑了一下："您说得对。我什么也不是，您看我的眼神像是看什么社会渣滓。唐彦的确值得更好的，只是我不能再失去他。"」——人物接受离开的要求，却明确保留回来追求对方的决定。这里的关键是接受了哪项条件、坚持了哪项诉求；它不证明所有谈判都能靠示弱取胜。
