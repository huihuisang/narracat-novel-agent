# 危机中的行动（crisis-action）

让读者看清威胁、应对和后果。

### [runtime] 写法参考

- **机制注解**：先交代人物眼前有什么危险，以及他还能做什么，再选择值得展开的行动。突然遇袭时，他可能先躲再判断；慢慢发现异常时，他也可能迟疑、求证或向人求助。行动顺序应符合人物当时掌握的信息。

  展开能改变局面的动作。连续动作需要让读者看清谁对谁做了什么、结果怎样，不必逐个拆成短句。调查和验证只保留增加证据、改变判断或造成后果的步骤，其余可以概述。恐惧写到具体顾虑上：他怕失去谁、暴露什么，或做错哪一步。

- **适用场景**：
  - 追击、搏斗、逃生，以及必须迅速作出选择的险境。
  - 人物从一次行动的结果中发现威胁。
  - 异常逐步得到确认，人物需要调整办法的场景。

- **不可迁移边界**：
  - 不为加快节奏改变章纲事件、既定行动或结局。
  - 不默认危险越大，句子就越短；缓慢察觉的恐惧也可以展开。
  - 人物不能行动时，写清限制和仍然可作的选择，不用连续身体反应代替应对。
  - 人物可以误判，但叙述不能把猜测当成已经确认的事实。

---

### [evidence] 真人证据（保留原有摘录）

- 真人证据：「方先野一边将房间内的东西都归置整齐，一边思索这次失窃难道真的只是意外遭了贼么？……他亲自把卧房收拾干净再去书房查看损失，走到书房刚看了一圈。他便心中一紧暗叫不好，疾步跑回卧房去，低头去看床底。那装着密旨的暗盒，已经不见踪影。这是个局！以失窃引出他的心急，让他去查看自己最要紧的秘密，便知道他的秘密藏在何处，趁他再次离开时才实施真正的偷窃。」——人物察觉不对后回到卧房检查，发现暗盒失踪，才意识到自己的动作可能暴露了秘密。值得借鉴的是行动、发现和判断之间的联系；这段也有直接的心理解释，不能据此要求危机场景一律删掉内心描写。
