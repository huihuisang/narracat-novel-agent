# 动作中的喜剧（comic-action）

让人物想做的事与实际效果产生可信的反差。

### [runtime] 写法参考

- **机制注解**：先明确人物的目的和在场的人如何理解他的行为，再写实际结果。人物想保持体面却忙中出错，旁人以为他会紧张而他照常办事，都可能产生喜感。行为必须有自己的理由，不能只为逗笑读者而发生。

  写清关键动作和结果，读者懂了就继续往下。旁观者可以反应，也可以没有旁观者，让读者独自看见反差。动作可以连续叙述，不需要每个动词单独换行，也不必在笑点后补一段“众人都愣住了”。

- **适用场景**：
  - 乌龙、出糗、误会，或人物刻意维护体面的场合。
  - 正式场合中符合人物习惯的日常举动。
  - 关系试探中，一次行动产生了意料之外的效果。

- **不可迁移边界**：
  - 不为笑点改变关键决定、造成新的重大损失，或引入章纲未定的不可逆后果。
  - 不以人物数量、信息层数或句子长度规定喜剧是否有效。
  - 不反复让同一个人出糗，也不把配角写成只会惊讶的观众。
  - 悲伤和危险中的幽默须有角色与关系依据。

---

### [evidence] 真人证据（保留原有摘录）

- 真人证据：「段胥从自己的营帐出来时只穿了一身便装红色圆领袍，头发也只是梳了个高马尾没有束好。沉英跟在他身侧抱着个筐，框里面装着一件银白铠甲。他从筐里拿出自己的铠甲，一边闲庭信步一边穿上，悠然地系好系带打好结，不慌不忙地把每部分穿妥帖。他走了一路，便在众目睽睽之下穿了一路，这架势仿佛是在南都街头试一件新衣似的。走到秦帅大营之前时段胥正正好戴上自己的腕扣，便正正衣服走进了营中。」——在正式军营场合，人物边走边穿铠甲，像平常试衣服一样从容。反差来自场合与态度，不是来自动作被切成多少句；可以借鉴这一点，不照搬行头与人物姿态。
