# 感官与场景（sensory-spectacle）

选择人物会注意的细节，让读者看清环境及其影响。

### [runtime] 写法参考

- **机制注解**：先确定人物站在哪里、正在做什么，哪些环境信息会影响他的行动或感受。宏大场景可以交代整体，再选择近处的细节；狭小场景也可以直接写清，不必把每处环境都变成情绪象征。

  细节有主次。紧张的人可能注意声音，等人的人可能留意门口，但实际选择应符合当前处境。描写不仅说明看见了什么，也可以呈现它带来的限制、帮助或变化。连续行动中，只留下读者理解动作所需的空间信息。

- **适用场景**：
  - 新环境、奇观、异象，或人物首次进入陌生场所。
  - 环境条件影响行动、关系或判断的场景。
  - 安静时刻中，人物的注意力发生变化。

- **不可迁移边界**：
  - 不为画面感改变既定天气、伤势或异常规则；未定的环境细节应与地点、时令和场景相符。
  - 不同时堆满位置、数量、声响、气味和身体特写。
  - 感官描写须符合距离、遮挡和当前视角；想象与真实感知要分清。
  - 反差可以使用，但不把美与危险、日常与灾难并置成每次出场的模板。

---

### [evidence] 真人证据（保留原有摘录）

- 真人证据：「他们一个站在屋檐下,一个跪在雪地之中，隔着茫茫纷飞的雪花，仿佛隔着深不可见、底无法跨越的鸿沟。……阳光一点点暗下去，风越来越萧瑟，雪花在天地之间飘飞，落在段胥的发间、肩膀、袖子上,他身上渐渐覆盖了一层薄雪，脸色越发苍白下去，目光远远地落在远方。」——屋檐与雪地中的位置差异让关系处境可见，积雪又标明时间在过去。可以借鉴环境如何参与场景，不必照搬风雪来表示所有关系的冷淡。
