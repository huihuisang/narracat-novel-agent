# 期待的兑现（payoff-delivery）

让已经铺垫的能力、判断或选择产生可见结果。

### [runtime] 写法参考

- **机制注解**：先确认读者在等什么，再把本章实际兑现的结果写清楚。能力展示需要让人理解难在哪里；真相揭露需要能对应已有线索；关系转折需要回应此前的犹豫和行动。

  关键动作、证据或台词可以展开，重复的过程可以省略。结果之后留出必要反应，让人物调整计划、态度或关系，不让旁观者轮流夸赞。短句、连续动作和感官描写都是可选手段，不是兑现期待的固定顺序。

- **适用场景**：
  - 已有铺垫的反击、能力展示、身份确认或真相揭露。
  - 一个长期目标在本章获得结果。
  - 人物作出此前不敢作的选择，并承担相应后果。

- **不可迁移边界**：
  - 不提前兑现章纲留到后面的结果，不添加新的能力或证据救场。
  - 不把惊讶、鼓掌和生理反应当成结果本身。
  - 不规定每次兑现都要静、动、静，或用多少次后必须插入平静段落。
  - 结果可以克制、复杂或带有损失，不必一律写成碾压。

---

### [evidence] 真人证据（保留原有摘录）

- 真人证据：「真正纵马驰骋的时候其他人和段胥之间的差距就显现出来，公子们都是从小练习骑术的，姿态优美风度翩翩，马也是风驰电掣的良驹，但是以飞一般的速度交会时多少害怕相撞摩擦，下意识就会放慢速度或避让。但段胥不会。他从最开始纵马速度就是最快的，疾风一般冲向场中，便是要与其他人撞上了也丝毫不避，一蹬马镫便侧身让过而来的人，同时挥手一击，尘土飞扬间彩球便被他击中高高地扬起，瞬息之间他又旋身稳稳地踩回了马镫上，这是何等精妙的控制和自信。」——节选先写其他骑手为何避让，再展示主角的不同选择与控制能力。参照让读者理解难度，动作让差异得到证实；无需移植原文的短句位置或连招句式。
