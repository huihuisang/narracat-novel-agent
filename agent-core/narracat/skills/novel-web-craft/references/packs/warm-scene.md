# 关心与日常相处（warm-scene）

通过人物怎样对待彼此，让关心落到具体事情上。

### [runtime] 写法参考

- **机制注解**：温情可以来自一句直接的关心，也可以来自一次记得、照顾或让步。先看人物眼下需要什么，另一个人是否注意到了，又愿意为此做什么。不必把情感全部藏进物件和身体感觉。

  日常细节要与这段关系有关。送饭、递衣服、替人处理麻烦可以展开，但不要把每顿饭都写成亲情象征。对话与行动已经表达关心时，少补“他终于明白她在乎自己”之类的总结。玩笑是否出现，取决于双方此时有没有心情接住它。

- **适用场景**：
  - 照顾、守护、和解，以及长期相处中的一次体谅。
  - 人物接受帮助，或开始考虑别人的处境。
  - 紧张事件之后，需要处理疲惫和关系余波的时刻。

- **不可迁移边界**：
  - 不为温情改写章纲中的分歧、伤害或关系状态。
  - 不要求每次关心都附带误会、悬念或调侃。
  - 不靠临时旧物、体温比喻和固定身体反应制造感动。
  - 关心可以有笨拙、边界和冲突，不把人物写成只会照顾别人的工具。

---

### [evidence] 真人证据（保留原有摘录）

- 真人证据：「步重华听见自己的心跳一下一下，由重转轻，由急转缓，被一股奇异而无形的力量抚平了，所有难以名状的烦躁和焦虑都消失得无影无踪。"你散步的方式太激烈了吧，队长？"」——节选用一个人的出现和一句调侃表现关系中的安心。可以关注谁的出现改变了人物状态；心跳变化与玩笑都只是这个场景的写法，不是温情段落必须具备的步骤。
