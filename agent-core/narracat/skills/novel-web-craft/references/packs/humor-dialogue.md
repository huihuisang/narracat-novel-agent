# 幽默对话（humor-dialogue）

让笑意来自人物的理解差异和回应方式。

### [runtime] 写法参考

- **机制注解**：先弄清人物这句话想达到什么，对方又听成了什么。笑点可以来自误会、一本正经的歪理、意外的回答，也可以来自熟人之间知道分寸的调侃。人物说话仍要回应眼前的人和事，不轮流替作者抖包袱。

  对方以为会得到帮助，却听到一句拆台的话，是一种写法；人物说了实话，别人却当成玩笑，是另一种写法。选择与当前关系相符的一种，不必先铺期待、再急停、最后补吐槽。笑点落下后继续让人物办事，读者已经懂了，就不再解释哪里好笑。

- **适用场景**：
  - 熟人斗嘴、初遇破冰，或不同理解造成的误会。
  - 一方想保住面子，另一方无意或有意拆穿。
  - 情绪缓和后自然出现的打趣。

- **不可迁移边界**：
  - 不为笑点改变章纲事件、人物决定或设定。
  - 不让配角突然变笨，也不让所有人共用一种机灵腔。
  - 沉痛或危险尚未过去时，是否开玩笑取决于人物习惯和双方关系。
  - 铺垫长短由场景决定，不规定几句话必须出一个包袱。

---

### [evidence] 真人证据（保留原有摘录）

- 真人证据：「没想到无尘却不乐意的说道，"白姑娘怎么能这么说呢？"秦月凉心中一喜，哟呼，这是知道帮她说话了？可以啊，有长进！在心里夸了他一番，她压下心头窃喜，正要说话，就听到无尘再次开口。"什么一腔爱意，白姑娘感觉错了，我明明就是在故意恶心她啊！"说着，无尘给秦月凉抛了个媚眼儿，"还是阿凉懂我。"」——人物先以为有人替自己说话，下一句却推翻了这个期待。可以借鉴回应方向的变化，不照搬其中的口头禅，也不要求每场对话都先助攻再拆台。
