# 关系中的试探（romance-tension）

让靠近、退让与回应符合两人的处境。

### [runtime] 写法参考

- **机制注解**：先确定两人怎样看待这段关系，各自想靠近到什么程度，又有什么顾虑。一次邀请、触碰、回避或承诺，只有改变了双方的理解，才值得展开。

  写当前人物会留意的反应，也可以直接写他的念头。对方沉默了多久、是否接受帮助，可能比耳红和手抖更重要。人物误解对方时，把判断留在他的认知范围内，不替另一个人确认心意。连续动作和思考可以放在同一段，不逐个放大身体部位。

- **适用场景**：
  - 关系未明确时的试探、靠近和退让。
  - 已有关系中，双方重新理解彼此需要的场景。
  - 外部处境迫使两人作出回应或选择。

- **不可迁移边界**：
  - 不为暧昧改写关系阶段、人物意愿或章纲事件，不临时增加关键误会和告白。
  - 不把迟疑、脸红等反应自动解释为爱意。
  - 不要求人物先否认再承认，也不刻意把每次坦白打断。
  - 尊重双方意愿和既有性格，不把无视拒绝当成浪漫。

### [evidence] 真人证据（保留原有摘录）

- 真人证据：「顾彻把人拉上来。目光瞥见他发梢的泥屑，下意识地伸手。手指碰到耳尖那瞬间。两个人的表情皆是一愣。"有泥屑，你的头发。"顾彻说着，手指却没立刻松开。于是，他看着那只耳朵从白皙转变为粉红，指尖的触感都在发烫。升级过的全息链接，神经反馈灵敏且真实。顾彻毫不怀疑，就算在线下，秋白白的反应也会是这样。」——接触有清楚的起因，人物随后注意到停留的手和对方反应。可以借鉴这一视角选择，但不能由一个身体反应确认全部心意，也不必沿用逐句切割动作的方式。
