# 失去与悲伤（grief-strike）

写清失去了什么，以及这件事怎样改变人物的生活。

### [runtime] 写法参考

- **机制注解**：先让读者理解这段关系、原有生活和眼前的失去。悲伤可能当场显露，也可能在一件寻常小事里重新出现。反应取决于人物经历、关系和当前处境，不统一压成沉默，也不统一写成崩溃。

  选择会改变行为的细节：原本要打给谁的电话、无人再用的东西、无法照常完成的事情。需要时可以直接写心理，不强迫读者从每个动作里猜。留白用于已经能够理解的部分，不省掉关键关系和原因。

- **适用场景**：
  - 诀别、死亡、离开、背叛，或生活方式的失去。
  - 人物回到熟悉场所，发现自己无法再照旧生活。
  - 一次确认使旧有期待落空，或使积压情绪发生变化。

- **不可迁移边界**：
  - 不额外制造死亡、疾病或伤害来提高情绪强度。
  - 不规定悲伤必须克制、必须先平静再流泪。
  - 反应过密时可以压缩，不用连续泪水和身体特写替代具体失去。
  - 已经表达清楚的情感不再反复解释，也不让悲伤承担每次章末钩子。

---

### [evidence] 真人证据（保留原有摘录）

- 真人证据：「他查了一下那几个酒店的评分，选择了自己的午餐，然后摇着轮椅出去了。他没有去餐厅，而是去了停车场。上车关好门，把轮椅折叠起来，放到副驾驶座。然后发动引擎。他戴着骨传导耳机，跟着导航上了路，大概开了十多分钟，从大路转到了小路，又开了五分钟，停到了露天停车场。然后他愣住了。因为面前是另外一所大学，也是他的母校。从车祸后，他就没有回来过。这样骤然来到母校附近，让他有些不知所措。正是中午，校门口进出的学生很多，他们很好，青春又健康，挂着笑容，讨论着午餐去哪里吃，周末安排什么活动。他有些失神地看着那些四年前也属于自己的画面，低头看到了自己的膝盖，还有空空荡荡的小腿下面。然后他默默把车开走了。」——熟悉的校园和人物如今的身体状况联系起来，使一段日常出行有了新的意义。读者能理解他为什么离开，才不需要更多解释；不可只复制开车、低头、沉默等动作来表现悲伤。
