# 叙事节奏与篇幅（pacing-rhythm）

按事情的重要程度安排展开、略写和停顿。

### [runtime] 写法参考

- **机制注解**：节奏取决于读者何时获得信息、人物怎样行动，以及哪些变化值得停留。关键选择、关系变化和无法撤回的行动可以展开；重复劳动、赶路和已经明白的过程可以概述。

  句子长短服务于当前体验。紧张可以用短句，也可以用连续思考；平静可以展开，也可以直接带过。同一组动作、观察或思考通常放在同一段，换人说话、场景变化或注意力转移时再分段。真正值得强调的发现可以独立成段，不按句号换行。

  场景后的心理只写新的顾虑或决定，不再把刚才的事翻成概念、比喻和金句。普通叙述负责衔接，让重要变化有空间。

- **适用场景**：
  - 重复检查过长，人物反应和选择被挤到后面。
  - 多个场景需要切换，或一段时间需要概述。
  - 重要发现、决断、反转和关系变化需要突出。

- **不可迁移边界**：
  - 不通过改写事件、改变既定因果顺序来追求节奏。
  - 不规定某种手法一章只能用几次，也不强制收、蓄、爆发的顺序。
  - 不把“简洁”理解为连续碎句，不把“完整”理解为解释所有推理。
  - 不用无意义的小动作、身体反应和环境描写填补删掉的内容。

### [evidence] 真人证据（保留原有摘录）

- 真人证据：「步重华一回头，手上拎着半截染血的碎酒瓶，头发凌乱，眼底森寒，慢慢闪烁出再也无需按捺的暴戾。"来啊，"他轻声嘲讽道，"看谁艹谁大爷？"金链男纵身就去抓地上那把砍刀，步重华扬手一甩，那染血的碎酒瓶在半空中呼呼打旋，铛一声重响将金链男头打得一歪，口鼻冒血地倒了下去。之前被踹飞出去的黄毛捂着胸口怒叫一声，发了疯似的撞过来冲步重华后背狠砸，板凳应声散架，步重华眼都没眨，反身抓住黄毛领子，拖行几步来到电线杆边，哐！哐！哐！毫不手软地把他头顶往水泥柱上猛撞！」——节选在嘲讽之后写连续打斗，声音和动作使力度发生变化。有效之处在于动作与结果清楚、场面有变化；这不是拟声词、短句和独立断行可以通用于所有高潮的依据。
