# 章末期待（chapter-end-hook）

从本章已经发生的事情里，留下读者关心的下一步。

### [runtime] 写法参考

- **机制注解**：先保留章纲规定的结尾事件，再看它留下了什么未完成的行动、尚待确认的信息或需要承担的后果。读者应知道人物眼前要做什么，同时仍想知道结果。

  一次决定、一个具体回应，或已经兑现后留下的变化，都可以作为结尾。不必一律截断对话、插入反转或把最后一句单独断行。事件已经让人担心时，不再补“他还不知道”“真正的危险才刚开始”等预告。

- **适用场景**：
  - 本章决定已经作出，执行或后果留待后续。
  - 一次发现改变了人物对局势的理解。
  - 关系暂时收束，但双方的选择仍有影响。

- **不可迁移边界**：
  - 不为增强悬念改写结尾事件、人物去向或设定真相。
  - 不扣留当前视角已经知道、且读者理解行动必需的信息。
  - 不让人物忽略可行办法，只为等到下一章或预定时刻。
  - 不额外安排惊吓、恶意误会或来历不明的声音；平静结尾也可以留下期待。

---

### [evidence] 真人证据（保留原有摘录）

- 真人证据：「可她还不知道，李意寻已经派人去给杨家送了一封信，信中没有多说别的，就只是描述了一下大皇子的病症以及死因。如今，这信还没送到杨家呢。」——节选明确交代信已经发出、尚未送达，读者因此期待收信者的反应。可以借鉴未完成行动带来的期待，不把全知预告或最后一句短句当成必需形式。
