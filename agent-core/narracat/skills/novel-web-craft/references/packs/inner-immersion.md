# 人物心理与选择（inner-immersion）

让读者理解他在担心什么，以及为什么改变办法。

### [runtime] 写法参考

- **机制注解**：围绕人物当前的目标写心理。新的见闻使他改变判断，具体顾虑又影响他是否开口、求助、退让或继续尝试。重要变化需要可理解的触发原因，普通念头可以简写，不把每一步都改成分析清单。

  心理可以直接叙述，也可以通过行为体现。选择哪种，取决于读者还缺什么信息。紧张不必总写心跳，隐瞒不必总写眼神；人物在熟人面前换了话题，或决定向原本不信任的人求助，也能体现变化。

  保持当前视角的知识边界。人物对别人的心思只能根据所见所闻判断，不能因为想得深入就自动猜中。相邻段落不反复解释同一情绪，动作已经说明的部分可以留白。

- **适用场景**：
  - 人物遇到难题，需要重新判断或作出选择。
  - 恐惧、羞愧、愤怒、期待逐步改变行为的场景。
  - 一段回忆确实影响当前决定的时刻。

- **不可迁移边界**：
  - 不为加强心理改写章纲中的决定和后果。
  - 不把职业术语、情绪标签或身体反应当成心理深度。
  - 不强制一种情绪顺序，也不要求每个动作后附一段解释。
  - 内心吐槽应符合人物声音；旁观者的解读要保留其局限。

---

### [evidence] 真人证据（保留原有摘录）

- 真人证据：「霍希撑着椅背，低头看她。这姿势像被他半抱在怀里，四周都是他的味道，盛乔感觉自己快窒息了。她艰难地抬头，齿缝中挤出几个音节："霍希……"对上他打量的目光。她半仰着头，一动不动看着他，离得这么近，连他的喉结都近在咫尺。一个念头在脑子里疯狂叫嚣。她死死捏着拳头，吞了吞口水，拼命克制，在心里一遍又一遍告诫自己一定不要冲动！」——人物在近距离接触中产生冲动，又努力克制。感官与念头都服务于同一个具体顾虑；这只是该场景的呈现方式，不能要求所有心理段落都安排气味、吞咽和攥拳。
